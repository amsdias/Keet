01 Signal chain

Applied in order on the decode thread. The audio callback is lock-free and allocation-free — volume is the only stage past the ring buffer.

decode→ to-stereo→ resample→ EQ→ effects→ ReplayGain→ crossfeed→ balance→ crossfade→ limiter→ ring buffer→ volume→ output

02 Capabilities

Playback

Gapless transitions — continuous stream across tracks
Equal-power crossfade — --crossfade
ReplayGain, track or album, with peak-based clip prevention
Session resume — track, position, volume, EQ, effects, theme
Shuffle with order restore · repeat all / one · play queue

Output

Device selection by name; format and rate enumeration
Exclusive mode — per-track rate matching, macOS hog mode
Automatic recovery from device disconnect (USB DAC, AirPods)
Mono, stereo, quad, 5.1 and 7.1 sources — ITU downmix to stereo
Bluetooth detection · conditional resampling · HQ resampler mode

Sound shaping

10-band parametric EQ — f64 biquads, AutoEq-compatible presets
Effects — reverb, chorus, delay
Meier headphone crossfeed — level, corner, interaural delay
Stereo balance · peak limiter · clipping indicator
Pre / post-fader metering

Library

Recursive folder scan, multiple sources, deduplicated
Artist → album → track tree with live filtering
Tag-based sort; parallel background metadata scan
M3U import and export · folder rescan
NAS libraries via any mounted SMB / NFS share

On screen

Eight visualisations, including a pixel-image analysis spectrogram
Album cover art — Kitty, iTerm2 and Sixel graphics, half-block fallback
Synced lyrics — embedded LRC, else fetched from LRCLIB
Three themes across all four screens
Artist / title / album / track from ID3, Vorbis and MP4 tags
CPU and memory stats via direct platform syscalls

System integration

OS media keys — MPRIS, SMTC, macOS Now Playing
AirPods stalk and Bluetooth headphone controls
OS seek bar and skip-by seeking
Now-playing metadata pushed to the system, throttled to ~1 Hz

03 Command line

# play files, folders and M3U playlists (deduplicated)
keet <file|folder|playlist>... [options]

# resume the last session
keet
Options
FlagArgumentEffect
-s, --shuffle—Randomise order. Re-shuffles on each repeat cycle.
-r, --repeat—Loop the playlist, rescanning sources for new files each cycle.
-q, --quality—HQ resampler. Higher CPU, inaudible difference.
-e, --eq<name|path>Start with an EQ preset by name, or a JSON file path.
--fx<name|path>Start with an effects preset by name, or a JSON file path.
-x, --crossfade<secs>Equal-power crossfade between tracks. 0 disables.
--rg-modetrack|album|offReplayGain mode. Default: track.
--device<name>Output device, matched by case-insensitive substring.
--exclusive—Per-track sample-rate matching; device lock (hog mode) on macOS.
--no-cover—Disable album cover rendering.
--themeclassic|minimal|hifiLaunch theme. Default: classic.
--list-devices—Print output devices with their formats and rates, then exit.
-h, --help—Print usage and exit.

06 EQ + FX editor — E

Ten fully parametric bands. Every band starts as a peaking filter on the ISO octave centres, so until you reach for the parametric keys it behaves as a classic graphic EQ. Editing any band switches the EQ to Custom and persists across sessions.

Custom presets are JSON files dropped into the folders below. The parametric EQ form accepts AutoEq exports directly — transcribe the ParametricEQ rows and copy the preamp line.

// ~/.config/keet/eq/my-headphones.json
{
  "name": "My Headphones",
  "preamp": -5.5,
  "bands": [
    { "type": "low_shelf",  "freq": 105,  "gain": 5.5,  "q": 0.71 },
    { "type": "peak",       "freq": 3300, "gain": -2.0, "q": 2.0 },
    { "type": "high_shelf", "freq": 9500, "gain": 1.5,  "q": 0.71 }
  ]
}

08 Configuration

Every key is optional and applies on top of the resumed session. An explicit command-line flag still wins.

// ~/.config/keet/config.json  ·  %APPDATA%\keet\config.json
{
  "theme":     "minimal",   // classic | minimal | hifi
  "viz":       "analysis",  // none | vu | spectrum | spectrum-vertical
                              // oscilloscope | lissajous | spectrogram | analysis
  "rg_mode":   "track",     // track | album | off
  "eq":        "Bass Boost",// any preset name
  "crossfeed": "off"       // off | light | medium | strong | custom name
}
Config~/.config/keet/config.json
EQ presets~/.config/keet/eq/*.json
Effects presets~/.config/keet/effects/*.json
Crossfeed presets~/.config/keet/crossfeed/*.json
Session state~/.config/keet/state.json
Crash log~/.config/keet/crash.log

On Windows every path above lives under %APPDATA%\keet\.

09 Install

# Linux/WSL first: sudo apt install libasound2-dev libdbus-1-dev
git clone https://github.com/amsdias/Keet.git
cd Keet
cargo install --path .

Release mode is not optional — a debug build cannot keep the decode thread ahead of the audio callback and will glitch. Point Keet at a mounted SMB or NFS share and network libraries work exactly like local folders.
